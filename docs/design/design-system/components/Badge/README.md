# Badge

A small pill with a dot and a word: the status colour is never alone. `.badge` + `.badge-neutral | info | warning | success | danger`; `.badge-live` makes the dot pulse (a pending or running state; off under reduced motion).

Not in the app code yet: proposed for the Workouts session status (`Planned` neutral, `In progress` warning + live, `Done` success) and the "Personal" exercise tag (info).
