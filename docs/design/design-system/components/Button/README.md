# Button

Every button in the app is `.btn` plus one variant; never a local chain of classes.

| Class | Use |
|---|---|
| `.btn-primary` | The main action of the screen, **once** (brand gradient + glow) |
| `.btn-accent` | Important secondary action, flat indigo |
| `.btn-soft` | Repeated actions, adding from a list ("+ Add set") |
| `.btn-secondary` | Neutral action, white with a border |
| `.btn-ghost` | Toolbar actions, Cancel |
| `.btn-danger` | Only a confirmed deletion |

Modifiers: `.btn-lg` (44 px tall, thumb-friendly on phones), `.btn-icon` (36 px square, icon only, needs an `aria-label`). Labels: verb first, sentence case.
