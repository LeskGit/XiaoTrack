# Field

The one text field of every form: `.field`, 40 px tall, `radius-md`, `line` border that turns `line-strong` on hover and `accent` with an `accent-soft` halo on focus.

Wrap it in `.field-label` (13 px label above the field). Numeric fields add `.tabular` and `inputmode="decimal"` (weight) or `"numeric"` (reps, seconds). An empty optional value shows the placeholder "—".
